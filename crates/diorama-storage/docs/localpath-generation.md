# Local-Path Resource Generation and Storage Configuration

## Purpose and Scope

This document details the generation of Kubernetes resources for `local-path-provisioner` in KubeSolo (`diorama-storage`), fulfilling Issue [#85](https://github.com/geoffsee/diorama/issues/85) (`[E18.01] Generate local-path resources and storage configuration`).

## Upstream Baseline and Parity

The resources generated by `diorama-storage` match upstream KubeSolo contract definitions (`pkg/components/localpath` at commit `2ef1c4787989f11f868f81bb84ae2afd4a49a81d`):

1. **Namespace**: `local-path-storage`
2. **ServiceAccount**: `local-path-provisioner-service-account`
3. **RBAC**:
   - `Role` (`local-path-provisioner-role`) in `local-path-storage`: permits `pods` get, list, watch, create, patch, update, delete.
   - `ClusterRole` (`local-path-provisioner-role`):
     - `nodes`, `persistentvolumeclaims`, `configmaps`, `pods`, `pods/log`: get, list, watch.
     - `persistentvolumes`: get, list, watch, create, patch, update, delete.
     - `events`: create, patch.
     - `storageclasses` (`storage.k8s.io`): get, list, watch.
   - `RoleBinding` (`local-path-provisioner-bind`) in `local-path-storage`.
   - `ClusterRoleBinding` (`local-path-provisioner-bind`).
4. **ConfigMap**: `local-path-config` in `local-path-storage`:
   - `config.json`: Formatted with 4-space indentation matching Go `json.MarshalIndent`.
     - When `sharedPath` is set: specifies `sharedFileSystemPath`.
     - When `sharedPath` is absent: specifies `nodePathMap` with `DEFAULT_PATH_FOR_NON_LISTED_NODES` pointing to the cluster's local path storage directory.
   - `setup`: Executable shell script creating directory with mode 0777.
   - `teardown`: Executable shell script removing directory recursively.
   - `helperPod.yaml`: Pod template for helper containers running setup and teardown.
5. **StorageClass**: `local-path`:
   - `provisioner`: `rancher.io/local-path`
   - `volumeBindingMode`: `WaitForFirstConsumer`
   - `reclaimPolicy`: `Retain`
   - `annotations`: `storageclass.kubernetes.io/is-default-class: "true"`
6. **Deployment**: `local-path-provisioner` in `local-path-storage`:
   - 1 replica.
   - Labels and selectors: `app: local-path-provisioner`.
   - Pod template with `serviceAccountName: local-path-provisioner-service-account`.
   - Container `local-path-provisioner`:
     - Image: `docker.io/rancher/local-path-provisioner:v0.0.36`.
     - Resources: Memory limit `128Mi`, CPU request `50m`, Memory request `32Mi`. This adheres to KS-68 removing earlier OOM-prone edge memory constraints.
     - Mounted ConfigMap at `/etc/config/`.

## Golden Parity Verification

Golden verification tests in `crates/diorama-storage/tests/golden_manifests.rs` load `tests/fixtures/localpath.json` (captured from upstream Go test execution in `tools/parity/fixtures/rust-evidence/localpath.json`) and assert exact object property parity across:
- `local` variant: host-backed directory paths.
- `shared` variant: shared filesystem paths.
